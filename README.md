# تطبيق إدخال بيانات (Flask + SQLite)

تطبيق بسيط لإدخال الاسم والعمر وتخزينهما في قاعدة بيانات SQLite داخل نفس المجلد.

## المتطلبات
- Python 3.9+
- نظام ويندوز (PowerShell)

## التثبيت والتشغيل
1) إنشاء بيئة افتراضية (اختياري لكنه مُستحسن):
```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```
2) تثبيت المتطلبات:
```powershell
pip install -r requirements.txt
```
3) تشغيل التطبيق:
```powershell
py app.py
```
4) افتح المتصفح على:
`http://127.0.0.1:5000`

## ملاحظات
- يتم إنشاء ملف قاعدة البيانات `database.db` تلقائياً عند تشغيل التطبيق لأول مرة.
- صفحة القائمة على الرابط `/list` لعرض كل المُدخلات.

## النشر على Render (خطة مجانية)
1) تأكد من وجود الملفات التالية في جذر المشروع:
   - `requirements.txt` (يتضمن Flask, gunicorn, openpyxl)
   - `Procfile` بمحتوى: `web: gunicorn app:app --workers=2 --threads=4 --timeout=120`
   - `render.yaml` يعرّف خدمة ويب ويضيف قرص دائم لمسار `/var/data` ويحدد `DATABASE_PATH=/var/data/database.db`.
2) ارفع المشروع إلى GitHub.
3) في لوحة Render:
   - اختر New → Blueprint (YAML) Deploy واختر المستودع الذي يحتوي `render.yaml`.
   - وافق على الإعدادات الافتراضية وسيتم إنشاء الخدمة والقرص تلقائياً.
4) عند أول تشغيل سيتم إنشاء قاعدة البيانات تلقائياً في القرص الدائم.
5) رابط التطبيق سيظهر بعد انتهاء النشر. إذا غيرت اسم الخدمة، سيتغير الرابط وفقاً لذلك.
